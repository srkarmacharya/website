date: 2026-11-20
summary: "One or two sentences that appear in link previews."
draft: true
---

Copy this file, rename it (for example `remittances-and-farm-labour.md`), change the
title, date and summary above, set `draft: false`, and write the piece below in plain text.

Leave a blank line between paragraphs. Use `## ` at the start of a line for a subheading,
`**bold**` for bold, and `[link text](https://example.com)` for links.

Pieces with `draft: true` are never published.
